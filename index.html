Hasil pencarian

Bagaimana AniCari bekerja?

Tanpa server, gratis selamanya

Semua pencarian berjalan di browser kamu dan situs ini adalah file statis yang di-host gratis di GitHub Pages. Tidak ada database, tidak ada akun, tidak ada pelacakan.

Sumber data terbuka

Anime dari AniList, foto dari Wikimedia Commons, dan video dari Internet Archive. Semuanya gratis dan ramah CORS.

Open source

Kode berlisensi MIT — fork, ubah, atau tambahkan sumber pencarian baru. Panduan ada di repositori GitHub.

Dibuat dengan ♥ — data milik sumber masing-masing.
