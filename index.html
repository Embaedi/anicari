Bagaimana AniCari bekerja?

Tanpa server, gratis selamanya

Semua pencarian berjalan di browser kamu dan situs ini adalah file statis yang di-host gratis di GitHub Pages. Tidak ada database, tidak ada akun, tidak ada pelacakan.

60+ sumber, pilih sendiri

Anime dari AniList, Kitsu, Jikan, dan Studio Ghibli; foto dari Wikimedia Commons, NASA, Openverse, TVmaze, Open Library, dan Disney; video dari Internet Archive, Wikimedia Commons, Dailymotion, dan delapan instance PeerTube. Centang yang kamu mau di menu Sumber.

Tambah sumber tanpa ubah kode

Tekan tombol Sumber di atas untuk menyalakan/mematikan penyedia, atau menambahkan API JSON apa pun sebagai sumber kustom baru. Konfigurasinya tersimpan di browser kamu.

Ingat progres & urutkan

Tandai episode yang sudah ditonton — AniCari mengingatnya di browser ini dan menampilkan baris Lanjutkan menonton. Hasil bisa diurutkan dari terpopuler, skor tertinggi, atau terbaru, dan kartu bisa diatur untuk langsung membuka situs sumber.

Open source

Kode berlisensi MIT — fork, ubah, atau tambahkan sumber bawaan baru di assets/js/api.js. Panduan ada di repositori GitHub.

Dibuat dengan ♥ — data milik sumber masing-masing.

Saat kartu diklik

Progres tontonan

AniCari mengingat episode terakhir tiap anime di browser ini — tanpa akun. Kamu bisa menghapusnya kapan saja.

Sumber kustom

Tambahkan API JSON apa pun yang mengizinkan CORS. Gunakan {q} untuk kata kunci dan {page} untuk halaman. Path memakai notasi titik, misalnya collection.items atau data.0.title. Sumber kustom muncul sebagai tab jenisnya (Foto/Video), bukan di tab Semua.
